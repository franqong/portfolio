###### Portfolio personal. Un espacio que usaré para compartir mis trabajos, experimentos y trayectoria en el sector del desarrollo de software. Este sitio está diseñado para ser rápido, minimalista y funcional.

## 🛠 Tecnologías

El portfolio ha sido desarrollado utilizando:

- **Framework:** [Astro](https://astro.build/)
- **Lenguaje:** TypeScript / JavaScript
- **Estilos:** CSS (Vanilla)
- **Deployment:** GitHub Pages

## 🚀 Proyectos Destacados

- **Penta:** Red social diseñada para el descubrimiento y feedback musical.
- **Penta Band:** Aplicación de escritorio dedicado a la composición musical.
- **Orestes:** Sistema de gestión de stock con arquitectura moderna y escalable.

## 📁 Estructura del Proyecto

<pre><code>/

## ⚙️ Desarrollo Local

Para ejecutar este repositorio localmente:

1. Instalar las dependencias:
   ```bash
   pnpm install
   ```
2. Iniciar el servidor local:
   ```bash
   pnpm dev
   ```
