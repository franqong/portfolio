###### Este es mi portfolio personal, un espacio donde comparto mi trabajo, experimentos y trayectoria como desarrollador de software. El sitio está diseñado para ser rápido, minimalista y funcional.

## 🛠 Tecnologías

El portfolio ha sido desarrollado utilizando:

- **Framework:** [Astro](https://astro.build/)
- **Lenguaje:** TypeScript / JavaScript
- **Estilos:** CSS (Vanilla)
- **Despliegue:** Vercel / GitHub Pages

## 🚀 Proyectos Destacados

- **Penta:** Red social diseñada para el descubrimiento y feedback musical.
- **Penta Band:** Aplicación de escritorio (C++/Qt) para la composición musical.
- **Orestes:** Sistema de gestión de stock con arquitectura moderna y escalable.

## 📁 Estructura del Proyecto

```text
/
├── public/          # Assets estáticos (imágenes, favicons)
├── src/
│   ├── components/  # Componentes reutilizables de Astro
│   ├── layouts/     # Estructuras base de las páginas
│   └── pages/       # Rutas y contenido principal
└── astro.config.mjs # Configuración de Astro
```

## ⚙️ Desarrollo Local

Si deseas ejecutar este proyecto localmente:

1. Instala las dependencias:
   ```bash
   pnpm install
   ```
2. Inicia el servidor de desarrollo:
   ```bash
   pnpm dev
   ```
